## How to present this to your professor

1. **The problem.** Fixed problem banks leak and get solved by AI. Puzzle questions don't teach
   real engineering. Debugging, the most common real task, is rarely taught explicitly.
2. **The idea.** An engine that generates realistic broken systems, proves them by running them,
   and supports many correct answers. The scope map (Figure 2.1).
3. **The demo.** Generate, investigate, fix, submit, rating (5 minutes, using the technical
   document's demo script).
4. **The plan.** Learn → Compete → Assess (Chapter 1). Phase 1 deliverables (Chapter 7).
5. **The ask.** A course section or lab for the pilot; a room and a date for Sprint #1;
   faculty sponsorship for an inter-college event next semester.
